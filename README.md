# apps.cancissu.com.br

Páginas públicas dos aplicativos CancissuBR, publicadas pelo GitHub Pages (domínio apps.cancissu.com.br, DNS na Locaweb).

- `/` — apresentação e lista de apps
- `/cpdf/` — página do CPDF (serve como site do app na Play Store)
- `/cpdf/privacidade/` — política de privacidade do CPDF (link usado na Play Console)
- `/caclick/` e `/caclick/privacidade/` — página e política do CAclick
- `assets/site.css` — estilo compartilhado (fontes do sistema, nada carregado de terceiros)

Esta é a fonte oficial da política de privacidade do CPDF.
